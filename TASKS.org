** TODO Reduce per-call overhead of the mplab-x CLI wrappers
:PROPERTIES:
:CUSTOM_ID: c5363e06-ee58-4439-b609-9c3de1b47b3e
:CREATED: [2026-10-20 Tue 17:02]
:END:
:LOGBOOK:
- Created [2026-10-20 Tue 17:02]
:END:
Each wrapped compiler call (e.g. xc16-gcc via mplab-x-run) took approximately 0.8 s (measured 2026-10-20, xc16 1.61): 0.52 s for the first program on the new fuse-overlayfs mount, 0.11 s for the rsync of the FHS rootfs, the remainder for mounts. Ten calls inside one environment took 0.9 s in total. After stage2 bind-mounted /nix (task dd8c0710), a wrapped call took approximately 0.37 s and mplab-x-run true 0.38 s, so the set-up is now the main cost. Possible approach: build the CLI root with bind mounts (bwrap) instead of fuse-overlayfs. Any new sandbox must keep the PRO licence: a default buildFHSEnv wrapper made xclm fail with "UID 0 not supported" (see task e00f895e).
