** TODO Pass installer options and pack names through for bundled and tool packs
:PROPERTIES:
:CUSTOM_ID: d69d03e5-6247-4fe6-8410-a1fdcf680717
:CREATED: [2026-10-22 Thu 20:06]
:END:
:LOGBOOK:

Goal: a thin layer with no per-release lists. Users write Microchip installer options and pack names; the flake passes them through. Proposed: (1) an installerArgs argument of mplab-x-unwrapped (default: the four MCU exclusion flags) and of its packs derivation (default: none), passed verbatim to the installer (options from `--help`: --ide, --ipe, --8bitmcu, --16bitmcu, --32bitmcu, --othermcu, and others); e.g. 16-bit device packs only with --8bitmcu 0 --32bitmcu 0 --othermcu 0. (2) The tool packs that the MCU-excluded installer run leaves (measured 2026-10-22, 6.35: 15 *_TP packs, 2.91 GB with arm/CMSIS; ICD3, PICkit 3, REAL ICE and PM3 have no tool pack, their support is in IDE jars) available without the full 14 GB installer run, e.g. a passthru derivation from the same installer flags. (3) A generic selection helper by <vendor>/<name> over any pack collection, so a user selects e.g. "Microchip/PICkit5_TP" without a list in this repository. (4) README.org: fetchMplabPack for tool packs from the repository (latest PICkit5_TP 3.0.1208 is served; the bundled 3.0.1195 and ICD5_TP 3.0.1102 return 403 and are absent from the current .pdsc release lists, so pinned old tool-pack versions can disappear upstream). Check: the installer group packs per option, store sizes, build-input graphs, and that the IDE lists a selected tool pack (GUI, user check). Includes the per-compiler pack sets of task aebb7421 (merged 2026-10-22): convenience selections of the bundled packs for each compiler (e.g. all xc16 device packs), preferably through the installer MCU groups (Microchip per-architecture groups) rather than rules of our own. A rule from the compiler subdirectory of each pack is not sufficient: of the 147 packs bundled with 6.35, 24 have xc8/, 21 have xc16/ and 45 have xc32/, and 57 have none, including about 40 device packs (PIC32C*, SAM*, MEC*) and arm/CMSIS (measured 2026-10-21). Measure which packs each installer MCU group installs. A set from the installer needs a local installer run; a set of fetchMplabPack pins does not.
