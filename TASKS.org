#+IMPORT: [[plan:2026-installer-pack-groups.org]]
Currently we install only those toolpacks specified explicitly via xc-cli customisation options.

Let's change this so that when no toolpacks are specified explicitly, all toolpacks for the specified compiler architecture(s) are installed by default, using the --<x>bitmcu arguments to the installer. This is a more convenient/user friendly option.

The --othermcu support packs should always installed -- they're small in context (4.8MB).

If there are other toolpacks relating to debugging tools etc. these should probably be included with the mplab-x package instead. That should also expose the mplab_ipe binary on installation (?should that also be offered as a standalone package?).
